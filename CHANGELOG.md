# Changelog
## 2.5.0
- Added a 90-day price-history sparkline in the web UI and refreshed the roadmap.
- Clarified API key generation and rotation guidance without committing secrets.
## 2.4.0
- Added `apps/price-agent-rag` and `apps/price-agent-plain` (with a Spring Boot 4.1 collector), CI for them, `docs/VARIANTS.md`.
## 2.3.0
- Per-environment files (`env/`), `.env.example`, `constants.py` for global values, config loader with start-up validation (fail fast in staging/production).
- Docs: CODE_GUIDE (architecture, flows), CODE_REFERENCE (generated by `tools/gen_code_map.py`), CONFIGURATION, STUDY_GUIDE. Docstrings on all functions.
## 2.2.0
- Price history (table, API, UI line), richer admin metrics, account deletion, evals harness and workflow, status/TODO roadmap, engineering process, ADRs, CONTRIBUTING, TERMS draft, PR/issue templates, Dependabot.
## 2.1.0
- Reviews and similar products (`kind=insights`, MCP tool, UI section); `docs/DESIGN.md` (DDD, HLD, LLD, flows, concepts).
## 2.0.0
- Async jobs on a thread pool with in-flight dedupe; SQLite persistence (cache, jobs, rate limits, users, OAuth).
- OAuth 2.1 authorization server (PKCE, dynamic registration, refresh rotation); OAuth-protected remote MCP server at `/mcp`.
- Cost tracking per job, admin stats, purge thread, output validation, test suite.
## 1.x
- Region-aware stores, location fallback, MCP stdio wrapper, API-key endpoint.
